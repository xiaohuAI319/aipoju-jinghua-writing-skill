# star-digest-skill · 知识星球精华帖撰写技能

一个面向 [WorkBuddy](https://www.workbuddy.cn) 的 Agent Skill：帮你撰写能入选**知识星球精华帖**的高质量文章。

基于某高活跃 AI 创业社群 **2000+ 条精华帖中 350+ 篇样本**（2023-2026）的规律分析提炼，沉淀出一套可复用的「六段式黄金架构」+ 联网素材采集 + 人机协作补素材的工作流。

## ✨ 核心特性

- **联网素材采集**：触发后自动搜集主题相关的行业动态、数据基准、爆款写法
- **强制互动补素材**：只有作者本人知道的经历、数据、踩坑细节，会一次性集中向你提问，绝不编造
- **六段式黄金架构**：钩子 → 自我介绍 → 痛点弯路 → 方法论 → 数据验证 → 复盘利他
- **信任链写作逻辑**：每段回答读者一个疑问，从"凭什么看你"到"我该怎么做"
- **自带红线清单**：编数据、纯广告、AI 腔等进不了精华的反面模式

## 📦 安装

将本仓库的 `SKILL.md` 放入 WorkBuddy 技能目录：

```bash
# 用户级（全局可用）
~/.workbuddy/skills/star-digest-skill/SKILL.md

# 或项目级（仅当前项目可用）
<workspace>/.workbuddy/skills/star-digest-skill/SKILL.md
```

## 🚀 使用

在 WorkBuddy 中说：

> 帮我写一篇星球精华帖，主题是：我用 XX 工具做了 XX，30 天拿到 XX 结果

Agent 会依次执行：**联网搜素材 → 盘点缺口向你提问 → 你补充素材 → 按六段式成稿**，最后交付正文 + 3 个备选标题 + 发布建议。

## 📖 精华帖黄金架构速览

```
标题 = 数字/时间/金额 + 具体成果 + 人群标签

① 开头钩子（前 3 行定生死）
② 自我介绍 + 起点（建立信任 + 代入感）
③ 痛点/弯路（最容易被点赞的段落）
④ 方法论/步骤（保姆级，读者能复现 80%）
⑤ 数据成果 + 验证（诚实标注口径）
⑥ 复盘感悟 + 利他收尾（SOP 拿走就能用）
```
